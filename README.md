# Cisco-Packet-Tracer-Network-Topology
This project is a multi-router and multi-switch network topology designed and simulated using Cisco Packet Tracer. The network includes several LAN segments connected through routers using subnetting and routing configurations.

The practical demonstrates:

-Router and switch configuration
-IP addressing and subnetting
-Inter-router connectivity
-VLAN/LAN communication
-End device configuration
-DHCP, DNS, and Web server setup
-Network testing and connectivity verification

All routers, switches, PCs, and servers were manually configured to establish successful communication across the entire network. This project was created as part of networking practical and CCNA-related learning activities.
